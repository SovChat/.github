📢 【Sov 技术团队招募公告】
核心定位：一支专注底层工程、极度硬核的小型精英开发团队。 背景：由2位来自SES的开发者发起，目前正在推进一个全新的、高强度的独立软件项目。
我们目前采取“小作坊、高标准”的模式，前期不设冗杂的管理，只看代码能力和工程素质，因此发此公告。
我们希望你具备以下品质：
	•	硬核工程素养：能独立解决环境依赖和编译问题
	•	自驱力强：具备主动研究、发现问题并提出解决方案的能力
	•	团队意识：愿意在核心项目上倾注时间

🧑‍💻 开放岗位
岗位一：后端开发工程师
技术栈：Go 语言 / 或者你能跟AI做mate（熟悉基础语法即可，项目中有大量工程实战可以打磨）。 你的工作：
	•	参与高并发服务的架构设计。
	•	实现/优化核心业务逻辑与文件系统或数据库的交互。
	•	配合前端完成 API 接口的联调与性能优化。  加分项：熟悉 Docker、网络协议（HTTP / WebSocket）、了解密码学基础者优先。
岗位二：前端开发工程师
技术栈：HTML / CSS / JavaScript（或主流前端框架）。
 你的工作：
	•	负责项目用户界面的搭建与交互逻辑实现。
	•	与后端工程师协作，完成数据渲染和异步请求。
	•	处理多端响应式适配及前端性能优化。  加分项：有 React / Vue 项目开发经验，或能独立设计高质感 UI 者优先。

📩 加入方式
如果你觉得自己的能力和态度都符合上述标准，请准备好：
	1	一段简短的自我介绍：说明你的技术栈和每周可投入时间。
	2	一份硬核的作品证明：GitHub 仓库链接、代码片段、或是过往的项目截图均可。
