# 简介

项目名称：Sov Chat

官方部署域名：https://chat\.bkyjx\.top

项目定位：一款开源、可完全自托管、轻量化网页即时群组聊天系统，主打私有化部署、数据自主掌控、极简高效的聊天体验，兼顾普通用户日常使用与开发者二次开发、迭代扩展。

## 一、项目通用介绍

Sov 是一套前后端分离的自研聊天系统，摒弃商业社交软件的冗余功能，聚焦核心群组聊天需求。整套系统完全支持私有化部署，所有聊天数据、用户数据均存储在使用者自己的服务器中，无第三方平台介入，数据安全性与私密性更高。

系统全程基于网页端运行，无需下载、无需安装客户端，任意设备通过浏览器即可接入聊天。同时具备完善的界面自适应、主题切换、消息排版优化能力，兼顾使用体验与视觉整洁度，适配日常多人沟通、小型团队协作沟通等场景。

## 二、普通用户使用说明

### 2\.1 核心功能介绍

Sov 提供稳定、简洁的网页群组聊天能力，核心功能贴合日常沟通需求，操作门槛极低：

1\. 基础消息发送：支持纯文本消息发送，支持长文本编辑，可通过快捷键实现多行文本换行，适配大段文字沟通场景。

2\. 智能消息排版：系统具备自动消息分组能力，同一用户连续发送的多条消息，仅第一条展示头像、用户名、时间信息，后续连续消息仅展示文本内容，自动紧凑排版；不同用户的消息组之间会自动展示分割横线，界面整洁无冗余空隙，视觉体验规整。

3\. 多主题模式：内置三套显示模式，分别为白天模式、黑夜模式、系统自适应模式，可手动自由切换。主题设置会自动本地保存，刷新页面、重启浏览器后依然保留用户偏好设置，同时全局页面背景、组件样式会同步适配主题，无视觉bug。

4\. 安全输入防护：所有输入内容均会自动做安全转义处理，杜绝恶意脚本注入，保障聊天页面安全稳定。同时会自动拦截纯空格空消息，避免无效消息发送。

5\. 动态成员展示：系统会自动识别聊天参与用户，侧边栏实时展示当前群组在线成员，新用户发言后会自动同步更新成员列表。

6\. 界面交互优化：消息发送后页面会自动滚动至最新消息位置，无需手动滑动；消息悬浮展示操作按钮，无悬浮时界面干净简洁，不占用视觉空间。

### 2\.2 基础使用操作

1\. 访问方式：任意设备打开浏览器，输入官方域名 https://chat\.bkyjx\.top 即可进入聊天页面，无需注册下载。

2\. 消息发送：输入文字后按下回车键直接发送消息；需要换行编辑长文本时，使用 Shift\+Enter 快捷键换行。

3\. 主题切换：点击页面顶部主题切换按钮，可自由切换白天、黑夜、自适应三种显示模式。

4\. 消息操作：鼠标悬浮在任意消息上方，可唤起消息操作按钮，支持消息回复、编辑功能（UI已完整适配，功能持续迭代中）。

### 2\.3 当前使用限制

1\. 当前仅支持网页端使用，暂无手机APP、桌面客户端版本，全平台依赖浏览器访问。

2\. 现阶段仅支持文本消息沟通，暂未开放图片、文件、表情包、语音视频等多媒体消息能力。

3\. 无自主注册功能，用户账号由服务器管理员统一配置、分配，普通用户无法自行注册账号。

4\. 服务可用性完全依赖部署服务器，服务器离线、网络异常时，聊天系统将无法正常访问和使用。

5\. 本地未对接后端时，页面仅支持模拟聊天，刷新页面后本地模拟消息会全部清空。

## 三、开发者技术文档

### 3\.1 项目整体架构

本项目采用标准前后端分离架构，分为前端静态客户端、后端Go服务两大模块，无重型开发框架，轻量化、易部署、易二次开发、适配所有主流服务器环境。

前端：原生 HTML\+CSS\+JavaScript 开发，零框架依赖，纯静态资源，可直接通过 Nginx 部署，适配所有浏览器。

后端：基于 Go 语言原生 HTTP 库开发的轻量化 API 服务（sov\-serverside），专注数据处理、账号认证、消息存储、接口分发，不承载任何静态资源服务能力。

部署架构：Cloudflare Tunnel 隧道服务 \+ Nginx 反向代理 \+ Go 后端服务，实现公网域名访问、静态资源分发、API 接口转发、全程HTTPS加密访问。

### 3\.2 前端项目详情

#### 3\.2\.1 文件结构

项目根目录仅包含三个核心文件，结构极简清晰：

```Plain Text
├─ index.html    # 页面唯一DOM骨架，仅保留结构标签，无内嵌样式、逻辑代码
├─ style.css     # 全局所有样式、主题样式、消息排版、交互样式
└─ script.js     # 全部业务逻辑、渲染规则、后端对接、配置参数
```

#### 3\.2\.2 核心技术特性

1\. 主题系统：主题标识挂载至根HTML节点，实现全局页面统一适配，修复传统主题切换局部变色bug，主题状态本地持久化存储。

2\. 消息渲染引擎：自研消息分组判定逻辑，精准区分连续用户消息、跨用户消息，自动实现消息合并、分割线精准展示，无多余空白、无错乱排版。

3\. 安全机制：所有用户输入内容强制HTML转义，彻底杜绝XSS脚本注入攻击，保障页面运行安全。

4\. 交互逻辑：textarea多行输入适配，区分发送快捷键与换行快捷键；消息自动滚动、空状态提示、悬浮按钮动态显示隐藏。

5\. 模拟调试模式：内置后端开关配置，可一键关闭网络请求，切换纯内存模拟聊天模式，方便本地UI调试，无需启动后端服务。

#### 3\.2\.3 后端对接规范

1\. 基础配置：所有核心对接参数统一集中在 script\.js 顶部 CONFIG 对象，支持一键修改域名、轮询间隔、用户信息。

2\. 认证方式：采用自定义请求头认证，请求携带 X\-User\-Id、X\-Password 两个自定义头部参数，与后端账号配置精准匹配。

3\. 数据交互逻辑：采用乐观渲染机制，发送消息优先本地渲染提升体验，后端请求失败自动回滚清空无效消息；通过时间戳增量轮询获取新消息，内置消息去重机制，杜绝重复渲染。

4\. 消息解析规则：适配后端标准消息格式 timestamp\|senderId\|ciphertext\|keysJson，预留E2EE端到端加密解析接口，可直接扩展加密能力。

5\. 公共扩展入口：全局挂载 ChatAPI 对外方法，支持外部调用接收消息，可无缝对接WebSocket实时推送，替代现有轮询模式。

### 3\.3 后端项目详情（sov\-serverside）

#### 3\.3\.1 基础信息

开发语言：Go

运行端口：默认本地监听 127\.0\.0\.1:8443

运行模式：轻量进程运行，支持系统服务托管、开机自启

存储方式：本地文件持久化存储消息数据，轻量化无数据库依赖

#### 3\.3\.2 完整API接口清单

1\. 健康检测接口：GET /health，用于检测后端服务运行状态

2\. 消息查询接口：GET /chat/messages，支持时间戳since参数增量获取历史消息

3\. 消息发送接口：POST /chat/send，接收前端消息数据，完成持久化存储

4\. 成员列表接口：GET /members/list，获取当前群组所有在线用户信息

5\. 文件资源接口：GET /files/，预留静态资源、附件传输接口

#### 3\.3\.3 核心运行规则

1\. 账号认证：服务启动时通过启动参数配置管理员账号密码，所有接口请求必须携带合法头部参数，无匿名访问权限。

2\. 数据格式：所有消息采用管道分隔行存储格式，结构简洁，便于解析、拓展、迁移。

3\. 跨域处理：原生不支持跨域，同源部署无需配置CORS；跨域场景需手动添加全局CORS中间件，禁止使用通配符配置，需精准匹配前端源地址。

### 3\.4 标准部署架构与规范

1\. 核心部署原则：禁止Cloudflare Tunnel直接代理Go后端8443端口，Go服务仅提供API接口，无静态资源能力，直接代理会导致公网访问根路径404。

2\. 标准部署流程：Cloudflare Tunnel 代理本机Nginx 80端口，由Nginx统一承接公网流量。

3\. Nginx分发规则：静态资源（html/css/js）直接本地读取响应，API接口（health/chat/members/files）反向代理转发至本地Go 8443端口。

4\. 部署优势：前后端同源访问，彻底规避跨域问题，无需配置CORS中间件，服务稳定性更高。

### 3\.5 已知问题与迭代计划

#### 3\.5\.1 现有待完善功能

1\. 消息回复、编辑功能仅完成UI，未对接后端交互逻辑

6\. 前端错误提示仅控制台输出，无用户可视化Toast提示

7\. 频道切换无历史消息缓存，切换频道数据会重置

#### 3\.5\.2 优化与迭代方向

3\. 替换轮询机制为WebSocket，实现消息毫秒级实时推送

4\. 拓展多媒体消息、附件上传、表情包能力

### 3\.6 开发调试说明

1\. 本地UI调试：修改script\.js中 CONFIG\.backendEnabled = false，关闭网络请求，使用内存模拟聊天，独立调试界面、排版、交互逻辑。

2\. 后端联调调试：开启backendEnabled，修改API域名、用户账号密码为服务端配置对应参数，通过浏览器Network、Console面板排查接口请求、数据解析异常。

3\. 线上故障排查：公网访问404优先排查隧道代理目标端口、Nginx配置；接口报错优先排查账号认证参数、CORS配置、后端服务运行状态。
